# SEO 이미지 최적화 앱

블로그용 이미지를 SEO 최적화된 WebP로 자동 변환하는 PC용 앱입니다.

## 기능

- **드래그 앤 드롭**: 이미지를 드래그 앤 드롭만 하면 자동 처리
- **AI 탐지 방지**: 매번 다른 조합의 실제 카메라 메타데이터 생성
- **서울 기준 GPS**: 서울 내 다양한 위치의 랜덤 GPS 좌표
- **WebP 변환**: 최적화된 WebP 형식으로 변환
- **가상 파일명**: 실제 카메라 파일명 패턴으로 자동 생성
- **원본 자동 삭제**: 처리 완료 후 원본 파일 자동 삭제

## 사용 방법

1. 앱 실행: `npm start`
2. 이미지를 드래그 앤 드롭
3. 자동 처리 완료

## 메타데이터 랜덤화

- 카메라 모델: 10+ 다양한 모델
- GPS 위치: 서울 내 50+ 위치
- 촬영 시간: 최근 7일 내 랜덤
- ISO, 조리개, 셔터 속도: 랜덤 조합
- 해상도: 다양한 실제 카메라 해상도

## 주의사항

이 앱은 메타데이터 측면에서 최대한 자연스럽게 만들지만, 100% 완전한 AI 탐지 방지를 보장할 수 없습니다. AI 탐지 시스템은 메타데이터 외에도 이미지 패턴, 픽셀 레벨 분석 등 다양한 방법을 사용합니다.
